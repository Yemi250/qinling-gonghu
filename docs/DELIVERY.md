# C 交付记录 — 2026-10-02

分支 `feat/backend`，版本 `0.1.0`。这是 C 后端的交接快照，不是全组比赛最终冻结。A/B 页面、D 模块和全组演示材料仍由对应负责人交付。

## 已实现

- 单 FastAPI 服务提供前端构建产物、SPA 回退、API 和本地图片。
- SQLite 持久化事件、图片绑定、分析版本、登录会话、责任人、处理材料与时间线。
- 六种状态与七个动作（补充、要求补充、派单、整改、结案、退回、驳回）的服务端校验。
- 环境变量演示账号、8 小时随机会话、注销；单事件游客凭证及管理员权限隔离。
- JPEG/PNG/WebP 校验、大小/像素限制、去除元信息、一次性绑定凭证；重复图片仅提示。
- 实际记录总览与中国时区今日统计，示范与规划点位清晰区分。
- D 模块适配、输入/输出契约、分析版本、错误脱敏、重试、超时/中断恢复与并发保护。
- OpenAPI 文档和生成 TypeScript 类型、公共 API 客户端、A/B 的目录骨架。
- 本地启动、Docker/Compose、持久化卷、CI 配置和真实 HTTP 验收脚本。
