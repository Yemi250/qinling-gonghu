# C 后端与集成实施计划

**Goal:** 交付 C 提示词约定的持久化 API、公共类型、AI 模块接入与可复制运行方式。
**Architecture:** 单进程 FastAPI + SQLite + 本地图片，React/Vite 仅建立团队入口；D 以异步 Python 模块接入。模型缺失时明确失败，保留材料并允许人工处理。
**Tech Stack:** Python 3.12、FastAPI、Pydantic、SQLite、Pillow、React、TypeScript、Vite。

任务书即已授权规格：`docs/团队任务/C_后端接口与集成.md`。本计划直接在 `feat/backend` 实施，不更改 A/B 页面或实现 D 的识别算法。

## 设计与取舍

- 采用标准库 SQLite，避免 ORM/迁移框架；短事务校验状态、写事件与时间线，AI 请求在事务外执行。
- 管理员通过环境变量配置的演示账号登录，服务端持久化有期限的随机会话。游客凭单事件随机凭证读取、补充、触发该事件线索分析；凭证仅存哈希。
- 上传返回随机图片 ID、展示 URL 与一次性绑定凭证，限制类型/大小/像素并重新编码去除元信息。图片 URL 是持有即可访问的随机链接；不要上传敏感照片。
- 六个业务状态与 AI 状态独立；分析记录有版本、材料版本和输入快照。并发分析拒绝，超时/中断可恢复，过期材料的 AI 结果不改变当前业务状态。
- D 提供 `backend.app.ai.provider` 的两个异步函数，输入输出以公共 Pydantic 类型校验；模块尚未提供时记录可重试失败，绝不伪造模型输出。
- 前后端共用 OpenAPI 生成的 TypeScript 类型。前端只显示工程就绪、实际总览以及文档入口，A/B 各自接入功能。
