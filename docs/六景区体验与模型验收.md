最初两轮验证遇到的是验收脚本问题：登录路径误写导致 405、浏览器选择器误写导致找不到对比区；均已修正。最后一轮三次调用及浏览器检查完整通过。先前失败轮次的临时数据库和证据也保留，不删除或覆盖。

## 复现方法

先按根目录 README 安装依赖、配置 `.env` 并构建前端。配置必须包含可用的 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY`。本机 `.env` 始终被 Git 忽略。运行真实模型验收会实际调用上游接口。

```text
uv run python -m scripts.live_ai_smoke
```

需 Node 与 Playwright Chromium；已有 Chrome 时设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 为绝对路径，Node 不在 PATH 时设置 `NODE_EXECUTABLE`。脚本启动随机本地端口和系统临时数据目录，使用随机隔离管理员密码，通过真实 HTTP 接口执行三次模型调用，再由浏览器读取保存结果。结束后停止隔离服务、保留图片、数据库、日志和 `evidence.json`。失败时不报告通过，证据含失败状态，运行应用中仍有重新分析与人工处理入口。

常规业务验收不调用真实模型：

```text
uv run ruff check backend scripts
uv run pytest backend/tests backend/tests_ai -q
npm --prefix frontend run build
npm --prefix frontend run test:e2e
```
