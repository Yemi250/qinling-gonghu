日期：2026-10-03。基线提交 `4d89e753f58e2fd3c3374f3c73c5367e5ed5fc0b`。三名外部智能体使用独立 worktree，总工程师检查实际文件、运行检查、集成组件并完成业务与真实模型验收。

## 已接通的能力

- 游客记录页：四阶段持久化证据分析、证据来源、处置建议、失败重试与过期提示；关联投稿看到共同治理回音。
- 管理员工作台：真实模型的关联依据与不确定项、候选照片、明确选择和确认归并、撤销、组内原材料、主事件接力处理。
- 整改核验：共同材料取样、实际送入图片范围、同图系统检查、真实模型前后对比、人工填写说明后结案或退回。
- 后端：版本2增量迁移与升级前 SQLite 备份；持久化后台阶段；严格同图自动归并；人工归并与撤销；材料和关系版本保护；独立投稿凭证及游客数据隔离。

完整规则与 API 见 [升级契约](EcoProof升级契约.md)。不同照片不会仅凭相似指纹自动归并，图片数量不会写成人数，照片真实性不会用虚构百分比表示。垃圾散落、堆积和满溢在候选检索时属于同一类日常问题，以免漏掉不同视角；自动归并仍要求双方具体类别一致。

## 复现

```text
uv run python -m scripts.export_openapi
npm --prefix frontend run generate:types
uv run pytest backend/tests backend/tests_ai -q
uv run ruff check backend scripts
npm --prefix frontend run build
npm --prefix frontend run test:e2e
uv run python -m scripts.live_upgrade_smoke
```

真实模型脚本需已配置 `.env`，Node在PATH、Playwright Chromium已安装；本机 Node 可通过 `NODE_EXECUTABLE=F:\node\node.exe` 指定，Chrome通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定。每次脚本独立隔离数据，保留失败材料，不自动删除目录。网络不可用时不宣称真实模型通过；应用继续提供重试和人工处理。
